# NYTimes API Explorer

A Python application that interfaces with the New York Times API to search articles and movie reviews, then displays the results in a structured DataFrame format.

## Features

- Search NYTimes articles (1851-present)
- Retrieve most popular articles
- Search movie reviews
- Convert API responses to pandas DataFrames
- Export results to CSV
- Interactive command-line interface

## Prerequisites

- Python 3.8+
- NYTimes API key (free tier available)
- pip package manager

## Setup

1. **Get an API key**:
   - Register at [NYTimes Developer Portal](https://developer.nytimes.com/)
   - Enable "Article Search API" for your application
   - Copy your API key
